## Overview
A native Android application for creating, organizing, completing,
editing, deleting, and sharing academic tasks.

## Features
- Add, edit, delete, and complete tasks
- Pending, completed, and overdue states
- Task filtering
- Room local database
- Light and dark themes
- Task sharing through Android Intent
- XML task-information panel inside a Compose screen

## Technologies
Kotlin, Jetpack Compose, Room, Navigation Compose, ViewModel, XML, Intent.

## How to Run
1. Clone the repository.
2. Open it in Android Studio.
3. Let Gradle sync finish.
4. Select an emulator or Android device.
5. Run the app.
